# 术语表 v0.1

| 英文 | 中文 | 一句话 |
|---|---|---|
| CDK (cyclin-dependent kinase) | 周期蛋白依赖性激酶 | 周期发动机，结合 cyclin 才有活性 |
| cyclin | 周期蛋白 | 随时期升降的 CDK 搭档，决定 CDK 何时、对谁起作用 |
| APC/C | 后期促进复合物 | E3 泛素连接酶，给 cyclin B、securin 等贴降解标签 |
| MPF | 促成熟因子 | 即 CDK1–cyclin B，驱动进入有丝分裂 |
| restriction point (R) | 限制点 | 哺乳动物 G1 晚期的不回头点，过点后不再依赖生长因子 |
| Start | Start 点 | 芽殖酵母 G1 的承诺点 |
| checkpoint | 检查点 | 前一步没完成或有损伤时，阻止进入下一步的监控机制 |
| SAC | 纺锤体组装检查点 | 所有动粒正确连接前阻止后期开始 |
| Rb | 视网膜母细胞瘤蛋白 | 结合并抑制 E2F 的刹车蛋白，被 CDK 磷酸化后松开 |
| E2F | E2F 转录因子 | 启动 S 期相关基因表达 |
| p53 | p53 | DNA 损伤后稳定，启动停顿、修复或凋亡 |
| p21 (CDKN1A) | p21 | p53 下游的 CDK 抑制蛋白，连接检查点与衰老 |
| p16 (CDKN2A) | p16 | 抑制 CDK4/6 的 INK4 家族蛋白，常见衰老标志 |
| Wee1 | Wee1 激酶 | 给 CDK1 加抑制性磷酸化 |
| Cdc25 | Cdc25 磷酸酶 | 去除抑制性磷酸化，激活 CDK1 |
| ATM | ATM 激酶 | 双链断裂的主要警报激酶 |
| ATR | ATR 激酶 | 单链 DNA/复制压力的警报激酶 |
| Chk1 / Chk2 | 检查点激酶 1/2 | 分别接收 ATR / ATM 信号，传给下游执行者 |
| γH2AX | 磷酸化 H2AX | 双链断裂位点的组蛋白标记，常用作损伤读数 |
| HR | 同源重组 | 以姐妹染色单体为模板精确修复双链断裂，限于 S/G2 |
| NHEJ | 非同源末端连接 | 直接连接断端，全周期可用，可能出错 |
| cohesin | 黏连蛋白 | 把姐妹染色单体绑在一起 |
| separase | 分离酶 | 切开 cohesin，启动后期 |
| securin | 分离酶抑制蛋白 | 抑制 separase，被 APC/C 降解 |
| kinetochore | 动粒 | 染色体着丝粒上连接纺锤体微管的结构 |
| G0 / quiescence | 静息期 | 可逆退出细胞周期 |
| senescence | 细胞衰老 | 不可逆停止增殖，常伴 p21/p16 升高 |
| SASP | 衰老相关分泌表型 | 衰老细胞分泌的炎症因子、生长因子和蛋白酶 |
| satellite cell (MuSC) | 卫星细胞（肌肉干细胞） | 位于肌纤维基膜下，Pax7⁺，平时静息 |
| FAP | 纤维脂肪祖细胞 | 肌肉间质祖细胞，参与再生，也是纤维化和脂肪浸润的来源 |
